# Curriculum Map

The curriculum has two overlapping routes.

## Route A — Priority Interview Path

Front-load the material most likely to be tested in a senior production-AI role:

1. Agent runtime and harness optimization.
2. Tool calling, model routing, memory, RAG, evaluation and observability.
3. Local/open model serving, vLLM concepts, GPU/Triton batching and Kubernetes scaling.
4. Python async/event loop, GIL, structured concurrency, cancellation and bounded concurrency.
5. PostgreSQL query plans/indexing/pools, DB-load reduction and caching.
6. Redis, Kafka, RabbitMQ, MQTT, Celery, backpressure and idempotency.
7. Load balancing, capacity estimation, failure handling and system-design process.
8. Transfer into real project architecture stories.

## Route B — Long-term mastery

### Phase 1 — Foundations
Python object model, mutability, complexity, core data structures and OOP.

### Phase 2 — Python backend mechanics
Generators, context managers, threading/multiprocessing, asyncio, FastAPI lifecycle, pools and profiling.

### Phase 3 — Data and databases
SQL joins, 1NF/2NF/3NF/BCNF normalization, window functions, indexes, EXPLAIN ANALYZE, transactions/locks, MVCC, caching, replicas, partitioning and sharding.

### Phase 4 — Distributed messaging and reliability
Redis structures, Kafka, RabbitMQ, MQTT, idempotency, retries, circuit breakers, backpressure, outbox and saga.

### Phase 5 — Machine-learning foundations
Splits, leakage, bias/variance, optimization, metrics, regularization, classical ML, neural nets, embeddings and drift.

### Phase 6 — Computer vision and video intelligence
Image tensors, preprocessing, CNNs, YOLO, IoU/NMS, SORT/DeepSORT, Kalman/Hungarian, ANPR, MMC, motion, scene sampling, face recognition and FAISS.

### Phase 7 — LLM/RAG/runtime engineering
Context engineering, retrieval, reranking, hallucination mitigation, tools, memory, model routing, local serving, evals, guardrails and observability.

### Phase 8 — System design
Capacity, APIs, load balancing, caching, CDN, replication, consistent hashing, distributed IDs, rate limits, large uploads and semantic search.

### Phase 9 — Reliability/security/operations
SLOs, tracing, graceful degradation, bulkheads, multi-tenancy, auth, prompt injection and cost optimization.

### Phase 10 — Senior/lead interview transfer
Architecture trade-offs, project walkthroughs, failure drills, leadership stories and CTO-level communication.
