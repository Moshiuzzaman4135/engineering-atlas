## 2. Confirmed work / portfolio context

Used for project anchors such as RAG, local AI/model routing, function calling, speech/translation integrations, large embedding search, and newer video/OCR experiments. Where a detail is not supported strongly enough, the app frames it as an upgrade/study path rather than claiming production ownership.

## 3. External general references

Official documentation is used for Python asyncio, Kafka, Redis Streams, RabbitMQ reliability, PostgreSQL indexing, Kubernetes HPA, NVIDIA Triton and vLLM/YOLO concepts. Learning-science references support retrieval practice and spacing.

## Accuracy rule

“Used by you” means there is supporting project/work evidence. A topic can still be priority study material even when you have not used that exact technology in production.
